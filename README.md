# RE-SEARCH LAB — ECONOMICS PORTFOLIO

Dark-mode economics/research portfolio website.

## Features

- **Design**: Dark graphite/moss/muted-rust research palette with economics-inspired charts and analytical grid
- **Archive Drawers**: Articles, Reports, Research, Data, Learning, and Digital sections
- **Publications**: Real Substack and CAP Rajasthan links showcasing published work
- **Downloadable Assets**: CV, Portfolio, and Full Work File (PDF)
- **Research Methodology**: Five-step research process visualization (Question → Evidence → Analysis → Interpret → Output)
- **Selected Work**: Six key research projects with descriptions
- **Social Links**: LinkedIn and Instagram integration

## Hosted On

This portfolio is deployed via **GitHub Pages** and live at:

**🌐 https://joshinandni91-commits.github.io/research-lab-portfolio/**

## Setup Instructions

### GitHub Pages Configuration

1. The site is automatically served from the `main` branch, root folder (`/`)
2. All files are in the repository root
3. GitHub Pages rebuilds on every push to `main`

### Customization

**Important**: Replace `YOUR_NANDINI_EMAIL_HERE` in `index.html` with your actual email address:

```html
<a href="mailto:your-email@example.com">EMAIL THE LAB →</a>
```

### Asset Paths

If you add PDF files or other assets, place them in an `assets/` directory at the repository root:

```
research-lab-portfolio/
├── index.html
├── README.md
└── assets/
    ├── Nandni-Joshi-CV.pdf
    ├── Nandni-Joshi-Portfolio.pdf
    └── Nandni-Joshi-Portfolio-All.pdf
```
